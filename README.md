## 📌 Sobre o Projeto

Este repositório contém o código-fonte, assets e documentação do jogo **MEC**, desenvolvido como **Projeto Integrador** para o curso de **Desenvolvimento de Software Multiplataformas** da **FATEC Registro**.

O objetivo do projeto é aplicar de forma prática os conhecimentos adquiridos em disciplinas como desenvolvimento de jogos, design de experiência (UX/UI), arte digital, arquitetura de software e gestão de projetos.

> *"E se dominar a Programação Orientada a Objetos fosse tão emocionante quanto desbravar um reino medieval?"*

### 📖 Sinopse / Enredo

> MEC — Mentes em Códigos — é um projeto educacional desenvolvido para o ensino de Programação Orientada a Objetos para alunos do ensino médio através de um jogo sério. O projeto utiliza uma metodologia gamificada, estruturada em cinco fases que evoluem da sintaxe básica até a automação via loops, visando reduzir a frustração dos estudantes com a complexidade abstrata da programação. Ao longo da jornada, o jogador precisa utilizar a lógica e sintaxe para interagir com o cenário e avançar pelos desafios.

---

## 🧠 Como o MEC funciona

O jogo liga diretamente o que o aluno digita ao que acontece na tela:

1. **Você escreve:** o jogador digita o código com os comandos do desafio.
2. **O jogo confere:** o interpretador verifica na hora se o código está certo.
3. **O personagem age:** se estiver correto, o personagem executa a ação (andar, pular, atacar).

Quando o aluno erra, as mensagens do jogo explicam com clareza como consertar o código, para que ninguém fique frustrado ou perdido.

---

## ✨ Principais Funcionalidades / Mechanics

- **Mecânica Principal 1:** Interpretador de código em tempo real que valida a sintaxe para acionar as ações do personagem (andar, pular, atacar).
- **Mecânica Principal 2:** Progressão de aprendizado em cinco fases (Sintaxe básica, Variáveis, Decisões condicionais, Funções e Loops).
- **Interface & HUD:** Design responsivo e acessível adaptado à identidade visual.
- **Sistema de Áudio:** Trilha sonora original e efeitos sonoros imersivos.
- **Level Design:** Fases desafiadoras com progressão graduada de dificuldade.

## 🚀 Como Executar o Projeto

### Pré-requisitos
- Ambiente de Execução da Engine / Navegador Web
- Git instalado na máquina.

### Passo a passo para rodar localmente

1. **Clone este repositório:**
   ```bash
   git clone https://github.com/eucoradin/Landing-page-P.I.git
   ```

2. **Abra o projeto no VS Code:**
   * Abra o **VS Code**.
   * Escolha **Abrir Pasta** e selecione a pasta clonada.

3. **Execute:**
   * Para ver a landing page, abra o `index.html` no navegador (ou use o **Live Server** do VS Code).
   * Para o jogo, abra a cena `MainMenu` ou `Level_01` em `src/Scenes/` na engine e pressione **Play**.
